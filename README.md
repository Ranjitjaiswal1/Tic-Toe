# 🎮 Cyber Tic-Tac-Toe (Player vs Computer)

A modern, responsive, ultra-sleek **Tic Tac Toe** web game featuring a dark glassmorphic cyber theme, intelligent AI opponents, real-time audio synthesis, particle celebration effects, and persistent statistics storage.

---

## 🌟 Key Features

- 👤 **Player vs Computer (Default Mode):** Play against an intelligent computer opponent powered by smart heuristic & Minimax algorithms.
- 🧠 **Difficulty Modes:**
  - **Smart Computer:** Balanced, responsive, and fun.
  - **Unbeatable AI:** Flawless Minimax strategy.
  - **2 Players (Pass & Play):** Play locally with a friend.
- 💾 **Permanent Stats Saving:** All your game records (Player Wins, Computer Wins, Draws, Win Rate %, Win Streaks, and Match History Log) are automatically saved in the browser using `localStorage`.
- 🎵 **Procedural Web Audio FX:** In-built zero-latency sound effects for moves, victories, and ties without external audio file dependencies.
- 🎆 **Winning Animations & Confetti:** Glowing animated laser strike-through line, tile pulsing, and canvas particle confetti celebration.
- 📱 **100% Responsive:** Flawlessly adapts to mobile phones, tablets, and desktop displays.

---

## 🚀 How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/Ranjitjaiswal1/Tic-Toe.git
   cd Tic-Toe
   ```

2. Open `index.html` directly in any web browser, or start a local server:
   ```bash
   npx serve .
   ```
